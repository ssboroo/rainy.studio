# RAINY Studio

Монгол хэлээр зураг, видео, дуу хоолой бүтээх хоёр студийн landing page.

- Хар орчин: Rainy Video, алтан лого, Higgsfield загварууд.
- Цагаан орчин: Rainy Voice, ногоон лого, ElevenLabs загварууд.
- Бороо, студи хоорондын шилжилт, жижиг хөвөх дүр, гар бичмэл хэвтэй бүтээгчийн үг.
- Гар утасны хувилбар, хөдөлгөөн зогсоох удирдлага, reduced-motion дэмжлэг.

## Ажиллуулах

Node.js 20 эсвэл шинэ хувилбар шаардлагатай. Гаднын npm dependency байхгүй.

```sh
npm start
```

Хаяг: `http://localhost:3000`. Railway-ийн `PORT` хувьсагчийг автоматаар ашиглана.

## Railway

Репозиторийг шинэ Railway service-тэй холбож deploy хийнэ. `railway.toml` нь эхлүүлэх команд болон `/health` шалгалтыг тохируулна.

`rainy.studio` домэйныг landing service дээр, `video.rainy.studio`, `voice.rainy.studio` домэйнуудыг холбогдох одоогийн service дээр тохируулна. DNS бичлэгт Railway-ийн тухайн service-д өгсөн утгыг ашиглана.

Одоогоор нүүр хуудасны товчлуурууд ажиллаж буй Railway URL-ууд руу орно. Subdomain-ууд холбогдсоны дараа `index.html` дахь холбогдох URL-уудыг солино.

Зураг, лого болон гар бичмэл фонт нүүр хуудсанд агуулагдсан. Manrope фонт Google Fonts-оос, дүрс тэмдэг Lucide CDN-ээс ачаална.

## Баталгаажуулалт

Студи солих, хөдөлгөөн зогсоох, дүр дээр дарах, бүтээгчийн үгийг хаах/Escape, фокус буцаах үйлдлийг локал шалгалтаар баталгаажуулсан. Browser дахь responsive дүрслэлийн бүрэн шалгалт болон production deploy хийгдээгүй.
